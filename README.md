## 使用说明

1. **先转存，再下载。** 打开分享链接后存到自己网盘，再从自己的网盘下载 —— 直接在分享页批量下载容易触发风控，链接也会更快失效。
2. **提取码**写在每条资源后面，格式如 `百度 k7k4 · 城通 2727`。
3. **链接失效**请在 [Issues](https://github.com/zhongyuanqi/waikan-zazhi/issues) 反馈，会尽快补链。
